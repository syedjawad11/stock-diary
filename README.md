# Invoice Match (working name)

A local invoice checker for a small importer. Reads a supplier invoice with an
open-weight model running on the laptop, matches it against the purchase order,
flags discrepancies, and drafts the dispute email. Nothing leaves the machine.

Built for the DEV Hacktoberfest Weekend Challenge: Build for a Friend (Oct 2026).

Setup, usage, credits and known limits are filled in before submission.
